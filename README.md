# snake.io
a slither.io style game im Java. Steer with the mouse, eat pellets to grow, and hold space to boost.

Requirements: Java JDK 17 or newer

Build

Open the project folder in a code editor and run the main.java file

Then you will enter the menu where you can enter an Username and press play to start.

Controls:
space - Boost
mouse - steer the snake

Goal:
Try to become the biggest snake and having the highest score. You can get different amount of points by eating pellets. 
you eat pellets by hovering over them with your head. The longer you get, the thicker your snake becomes and the slower it turns, so plan your turns.
Need to speed up? hold Space to boost It makes you faster, but you lose a bit of length and leave pellets behind. 
Watch out for other snakes! If your head runs into another snake, you die. Steer around them, or get other snakes to run into you.
